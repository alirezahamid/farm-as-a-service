The mark is a pair of code braces with a leaf inside. Code on the outside,
soil on the inside.

Use these files for talks, blog posts, stickers, and forks. They are under
the same [CC BY-SA 4.0](../LICENSE) license as the rest of the repo.

## Files

| Folder | What is in it |
| --- | --- |
| [`svg/`](svg/) | Logos and marks. The "FaaS" text is converted to outlines, so no font is needed. |
| [`png/`](png/) | Favicons, app icon, and logos with transparent backgrounds. Banner and social preview with a solid background. |

### Logo variants

| File | Use it on |
| --- | --- |
| `faas-logo-horizontal.svg` | Light backgrounds. The default. |
| `faas-logo-horizontal-reverse.svg` | Dark backgrounds. |
| `faas-logo-stacked.svg` / `-reverse.svg` | Square spaces. Avatars, stickers. |
| `faas-mark.svg` / `-reverse.svg` | Icon only. When space is tight. |
| `*-black.svg` / `*-white.svg` | One colour only. Photos, print, laser cutters. Braces and leaf are knocked out. |
| `favicon.svg`, `png/favicon-*.png` | Browser tabs. 16, 32, and 48 px. |
| `png/app-icon-512.png` | App icons and avatars. |

### Banners

| File | Size | Use |
| --- | --- | --- |
| `png/readme-banner-2400x600-2x.png` | 2400 × 600 | Top of the README. Shown at 1200 wide, sharp on retina screens. |
| `png/readme-banner-1200x300.png` | 1200 × 300 | Same banner at 1×. |
| `png/social-preview-1280x640.png` | 1280 × 640 | GitHub social preview. Upload it in **Settings → General → Social preview**. |

The banners have a solid background, so they look the same in GitHub's light
and dark themes.

| Field Green | `#3F7D3A` | Leaf on a light tile. Links. |

## Type

All free under the SIL Open Font License, on Google Fonts.

- **IBM Plex Mono SemiBold (600)**, tracking −3%: wordmark and headings.
- **IBM Plex Mono Regular (400)**: tagline and code.
- **IBM Plex Sans Regular (400)**: long body text.

## Spacing and size

- Clear space: ¼ of the mark height on every side.
- Minimum size: mark 16 px, horizontal logo 20 px tall, stacked logo 48 px
  tall.

## Don't

- Stretch, squash, or rotate the logo.
- Recolour the leaf.
- Put the dark tile on a dark background. Use the reverse version.
- Add shadows, glows, or gradients.
- Retype the wordmark in another font.
- Add a tractor.

Keep the jokes in the headings. Keep the logo boring.
