## Add yours

1. Copy [`templates/story.md`](../../templates/story.md) to this folder.
2. Name it `<year>-<short-name>.md`. Example: `2026-six-hens-in-leeds.md`.
3. Write 300 to 800 words. Include real numbers where you can.
4. Add a link to the list above.
5. Open a pull request.

It must be your own story. See [CONTRIBUTING.md](../../CONTRIBUTING.md).
